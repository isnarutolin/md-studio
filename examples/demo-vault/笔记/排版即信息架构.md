# 排版即信息架构

回到[索引](../README.md) · 上一篇[块级即时渲染](块级即时渲染.md)

## 视觉密度决定可读性

- **标题需要呼吸感** —— 上下留白比字号更重要
- **代码块需要容器感** —— 背景、圆角、语言标签
- **表格需要结构感** —— 表头背景、悬停高亮
- **引用需要层次感** —— 左侧竖线 + 缩进

> 排版不是装饰。排版是**信息架构的可视化**。

## 字号阶梯

| 层级 | 字号 | 用途 |
| :--- | ---: | :--- |
| H1 | 1.92em | 文档标题，一篇一个 |
| H2 | 1.50em | 主要章节 |
| H3 | 1.24em | 子章节 |
| H4 | 1.08em | 细则 |
| 正文 | 1.00em | 17px |
| 代码 | 0.85em | 等宽 |

## 段落节奏

短句。

中等长度的句子，用来测试行高与段间距是否舒服。

一个较长的段落，用来观察阅读时眼睛的移动轨迹。行宽限制在 760px 左右是刻意的：一行放得下 30～40 个汉字，正好是一次眼跳的舒适区间。超过这个宽度，读完一行回到下一行开头就容易串行。
