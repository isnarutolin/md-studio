# 块级即时渲染是怎么做的

> 一个优秀编辑器最该做的事，是让**工具消失**，只剩你和文字。

回到[索引](../README.md)。

## 问题的本质

传统 Markdown 编辑器把世界分成两半：左边写 `## 标题`，右边看标题。你的眼睛要不停地在两个坐标系之间**来回翻译**。

这不只是多花一秒，而是打断了心流——每次扫视分屏，你都在做一次「源码 → 语义」的解码。

| 方案 | 心流打断 | 视觉反馈 | 排版控制 |
| :--- | :---: | :---: | ---: |
| 双栏预览 | 高 | 弱 | 差 |
| 源码 + 侧边预览 | 中 | 中 | 中 |
| **块级即时渲染** | **低** | **强** | **强** |

## 三条规则

1. 光标离开这一行，`**粗体**` 立刻变成 **粗体**
2. 光标回到这一行，标记符号以淡色浮现，随时可改
3. 编辑器失去焦点时，**整篇都是渲染态**

第 3 条是这次加的。原先打开文档光标在第 0 位，导致第一行标题永远露着 `#`，对"只想看一眼"的人很不友好。

### 为什么不是全文所见即所得

完全隐藏语法会带来两个问题：**你不知道自己写的是什么**，以及**特殊字符没法精确编辑**。所以正确做法是「按需显形」。

## 三层装饰

| 层 | 提供方式 | 内容 |
| --- | --- | --- |
| 块级 | `StateField` | 表格、frontmatter |
| 行内 | `ViewPlugin` | 标题、强调、链接、图片 |
| 原子区间 | `ViewPlugin` | 被吃掉的语法符号 |

第一层必须是 `StateField`——CodeMirror 规定 block decoration 不能由 ViewPlugin 提供，因为它会破坏测量顺序。
