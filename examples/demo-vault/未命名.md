**在本地 HTML 上直接改内容，`Cmd/Ctrl+S` 存回原文件。**

   AI 生成的页面，改一句话就得让它重新生成一整份 —— 这个工具解决的就是这一步。

   装好之后：双击任意本地 `.html` → 右下角点一下 **✎** → 像改文档一样直接改 →
 `Cmd+S` 覆盖原文件。
   每次保存自动备份，改坏了随时一键回滚。

   ---

   ## 两种用法

   | | 适合 | 入口 |
   | --- | --- | --- |
   | **Chrome 扩展** | 想在哪改就在哪改 | 双击任意本地 html，右下角 ✎ |
   | **本地网页版** | 想一边浏览文件列表一边改 | `python3 server.py` →
 `127.0.0.1:7788` |

   两者互不干扰，备份各存一份。

   ## 安装

   ### Chrome 扩展（推荐）

   ```bash
   git clone https://github.com/isnarutolin/html-studio.git ~/html-studio
   cd ~/html-studio/extension
   python3 install.py
   ```

   脚本会自动找到你装了的 Chromium 系浏览器（Chrome / Chromium / Brave / Edge /
 Vivaldi）并注册本地程序。
   然后在浏览器里做三步：

   1. `chrome://extensions` → 开启**开发者模式** → **加载已解压的扩展程序** →
 选 `extension` 目录
   2. 扩展卡片 → **详情** → 打开 **「允许访问文件网址」**
   3. **完全退出浏览器再重开**

   > ⚠️ **第 2 步不开的话，本地页面上不会有任何反应，也不会报错。** 这是最高频
 的坑。

   忘了哪一步没做？**点浏览器工具栏的扩展图标**，会打开自检页，实时告诉你缺什么
 。

   ### 本地网页版

   ```bash
   cd ~/html-studio
   python3 server.py        # 打开 http://127.0.0.1:7788
   ```

   macOS 上还可以 `python3 service.py install` 注册成常驻服务：开机自启、崩溃自
 动拉起、记住上次打开的文件。
